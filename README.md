# Cloomba — Community & Issues

**[Cloomba](https://cloomba.com)** is an EU-hosted, GDPR-by-design event platform — RSVPs, paid
ticketing, and a live media wall for your events. Built in Europe, for Europe. Available on the
[web](https://cloomba.com), [iOS](https://apps.apple.com/app/cloomba), and
[Android](https://play.google.com/store/apps/details?id=com.cloomba).

> **This repository is for issues, feedback, and discussion only — there is no source code here.**
> It's where the community reports bugs, requests features, and talks with the team.

## How can I help?

| I want to…                         | Go here                                                                                                  |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 🐞 Report a bug                    | [New bug report](https://github.com/whitetown/cloomba/issues/new?template=bug.yml)                       |
| 💡 Request a feature               | [New feature request](https://github.com/whitetown/cloomba/issues/new?template=feature.yml)              |
| 💬 Ask a question or share an idea | [Discussions](https://github.com/whitetown/cloomba/discussions)                                          |
| 🔒 Report a security/privacy issue | [Privately, here](https://github.com/whitetown/cloomba/security/advisories/new) — **not** a public issue |
| 📧 Account, billing, or privacy    | [support@cloomba.com](mailto:support@cloomba.com)                                                          |

Please **search first** — your bug or idea may already be tracked. A 👍 or comment on an existing
item is more useful than a duplicate.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for what makes a good report, [SUPPORT.md](./SUPPORT.md)
for where to get help, and our [Code of Conduct](./CODE_OF_CONDUCT.md).

## About

Cloomba is built by two co-founders who care about events and about keeping European data in
