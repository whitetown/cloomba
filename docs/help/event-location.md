### In-person events

Enter a street address in the location field. Cloomba will show a map on your event page and use the location for city-based discovery — people browsing events in your area can find the event by location.

Try to be specific. A full street address is better than just a venue name.

---

### Online events

Enter the URL of your meeting room — Zoom, Google Meet, Microsoft Teams, YouTube Live, or any other link. The URL is shown only to people who have registered, so it stays out of the public event page.

---

### Hybrid events

Set both a physical address and an online link. Registered guests see both, and can choose how they join.

---

### Changing the location

You can update the location at any time after publishing. If the venue changes after people have already registered, use an event update to notify them directly.
