You can issue discount coupons on paid Cloomba events — flat amount off or percentage off, with optional usage limits and expiry. Useful for early-bird discounts, partner perks, comp tickets for speakers, or any private promo.

---

### Creating a coupon

On a paid event, open the **Coupons** panel and create a new coupon:

- **Code** — what attendees will type at checkout
- **Discount** — flat amount in the event's currency, or a percentage
- **Usage limit** — optional cap on how many times the coupon can be redeemed
- **Expiry** — optional date after which the coupon stops working

Coupons are tied to a single event — the same code on two events is two separate coupons.

---

### Sharing the code

Send the code wherever your audience is — newsletter, Slack, a partner's site, a printed flyer. Anyone with the code can apply it at checkout.

If a coupon should reach only specific people, send it privately and keep the usage limit low.

---

### Attendee experience

On the RSVP screen, attendees see a **Have a code?** field. Entering a valid code shows the new total before they pay. Invalid, expired, or used-up codes are rejected with a clear message.

---

### Managing existing coupons

The Coupons panel shows each coupon's redemption count. You can:

- Edit the code, discount, limit, or expiry
- Delete a coupon to disable it (existing tickets bought with it are NOT affected)

---

### Coupons + off-platform payment

Coupons apply on the platform price displayed to the attendee. For [off-platform payment](/help/off-platform-payment) where Cloomba doesn't see the money, coupons don't apply — express any discount in your payment instructions text instead.

---

### Coupons + fees

Cloomba's 5% fee is calculated on the **final** price after the coupon — so a coupon that drops the price to zero results in no Cloomba fee.
