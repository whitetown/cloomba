Plenty of events need sign-ups to stop before the doors open — a caterer needs numbers, badges need printing, a venue needs a final list. On Cloomba you set that deadline on the ticket type, not on the event.

---

### Setting the deadline

Open **Manage → Registration → Tickets**, edit a ticket type, and set **Sales end**. There is a matching **Sales start** if you want registration to open later rather than immediately — useful for putting an event page up early and taking sign-ups from a set date.

Both are optional. A ticket type with neither is open from the moment you publish until the event is over.

---

### Deadlines apply per ticket type

Each type carries its own window, and your event stops taking registrations only when **every** type is past its own **Sales end**.

That is what makes staged pricing work — early bird can close weeks before general admission, and the event stays open the whole time. It also means a type you left without an end date keeps the event open on its own, however many other types have closed. If you want the whole event to stop, set an end on every type.

A type that has not started yet does not close the event either — it is simply not available yet.

---

### What guests see when it closes

Once every type is past its deadline, the event page shows:

> Registration has closed for this event.

and the Join button disappears entirely, the same way it does when an event sells out. The "spots left" urgency line is hidden too, since it would contradict the message.

If your event has a single ticket type, the checkout screen also explains why the button is unavailable — **Sales ended**, or **On sale from** with the date when it has not opened yet.

---

### This is not a waitlist

A closed event does not offer a waitlist, and that is deliberate. The [waitlist](/help/waitlist) exists for events that are **full** — it queues people for a spot that might be released when somebody cancels. A closed event is not full; you have simply stopped taking names, and no cancellation is going to change that.

The two settings are independent. An event can be full but still open, open but past its deadline, or both.

---

### Letting somebody in after the deadline

Deadlines are for the public, not for you. If you [send someone an invitation](/help/invite-guests) **after** a ticket type's deadline has passed, that invitation works — you decided to open the door again for that person, and Cloomba does not second-guess you.

An invitation you sent **before** the deadline shares the deadline. It was an invitation to register while registration was open, and it expires along with it.

Hosts, co-hosts and event staff are never blocked by a sales window and can register at any time.

If you want to reopen the event for everybody rather than one person, clear or extend **Sales end** on the ticket types instead.

---

### Choosing a deadline

A few things worth thinking about:

- **Leave yourself the buffer you actually need.** Closing the night before helps nobody if you print badges two days ahead.
- **Say the deadline in the description too.** The event page shows it only once it has passed; before that, people just see a normal Join button.
- **Send a reminder before it hits.** An [event update](/help/event-updates) a few days out converts the people who meant to sign up and forgot.
