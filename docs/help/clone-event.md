Cloning lets you copy an existing event into a new draft. It is the fastest way to create a follow-up edition of a recurring event without starting from scratch.

---

### What gets copied

When you clone an event, the new draft inherits:

- Title, description, and cover image
- Event type (in-person, online, hybrid) and location or meeting link
- Visibility setting
- Ticket setup
- Capacity and guest approval settings

The **date and time** are not copied — the new draft starts with no date set, so you are prompted to fill it in before publishing. The guest list is not copied either — the new event starts empty.

---

### How to clone

1. Open the event you want to duplicate.
2. Go to the event's settings or management menu.
3. Select **Clone event**.
4. A new draft opens with all the copied details. Update the date, tweak anything else that has changed, and publish when ready.

---

### After cloning

The original event is untouched. Both events exist independently — changes to one do not affect the other.

If you run a series, add the new event to your calendar so followers are notified automatically.
