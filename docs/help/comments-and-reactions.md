Every photo and video on an event's [media wall](/help/media-wall) has its own comments and emoji reactions.

Open any post in the media wall to read its comments and add your own. Every post also has emoji reactions, which appear as small badges on the wall tile so you can see what's popular at a glance.

### Real-time

Comments and reactions appear live for everyone viewing the same event — no need to refresh. See [Real-time updates](/help/notifications-inbox) for the wider story.

### Organiser controls

In your event settings you can turn **reactions off** to disable emoji reactions on media posts. Organisers, admins, and moderators can also delete any comment or remove any reaction at any time — handy for spam or off-topic content.

### Looking for the event discussion?

Questions, logistics, and general chatter about the event live in its group chat, not here. See [The event chat](/help/event-chat).

### Reporting

If a comment breaks the [Acceptable Use Policy](/legal/acceptable-use), [report it](/help/reporting-abuse) so we can review.
