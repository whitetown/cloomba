## How to contact the event organizer

Message the organizer directly on Cloomba, ask in the event chat if you're going, or use the contact links on their profile.

## Send a direct message

1. Open the event page
2. Tap the organizer's name or profile photo to open their profile
3. Tap **Connect** and write your message — if you already have a conversation, the button reads **Chat**

Your first message arrives as a request the organizer accepts. See [Direct messages on Cloomba](/help/messaging).

## In the event chat

If you're registered, the event's **Chat** tab reaches the organizer, the co-hosts, and everyone going — a good place for questions other guests may have too. See [The event chat](/help/event-chat).

## On the organizer's profile

1. Open the event page
2. Tap the organizer's name or profile photo to open their profile
3. Use any of the links the organizer has published — website, email, social handles

Most active organizers add at least one way to reach them. If a profile has no contact links and the event is happening soon, see the next section.

## If you can't reach the organizer

Some questions only the organizer can answer (specific dietary requirements, accessibility, refunds for paid tickets). If the event is approaching and the organizer hasn't responded:

- Re-check the event description — many practical details are spelled out there
- Try any external link the event description points to (event website, community Slack/Discord)

For refund questions on paid tickets, see [Issuing refunds](/help/refunds).

## Questions about Cloomba itself

If your question is about the platform rather than the event, [contact us](/info/contact) — we're happy to help.
