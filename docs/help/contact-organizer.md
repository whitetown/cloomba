## How to contact the event organiser

Cloomba doesn't have a built-in direct-message inbox today, but you can still reach most organisers through the contact links they publish on their profile.

## On the organiser's profile

1. Open the event page
2. Tap the organiser's name or profile photo to open their profile
3. Use any of the links the organiser has published — website, email, social handles

Most active organisers add at least one way to reach them. If a profile has no contact links and the event is happening soon, see the next section.

## If you can't reach the organiser

Some questions only the organiser can answer (specific dietary requirements, accessibility, refunds for paid tickets). If the event is approaching and the organiser hasn't responded:

- Re-check the event description — many practical details are spelled out there
- Try any external link the event description points to (event website, community Slack/Discord)

For refund questions on paid tickets, see [Issuing refunds](/help/refunds).

## Questions about Cloomba itself

If your question is about the platform rather than the event, [contact us](/info/contact) — we're happy to help.

## What's coming

A direct-message inbox between users is on our roadmap. Until then, the contact links on the organiser's profile are the canonical way to get in touch.
