For conferences, workshops, and longer events, Cloomba supports a structured **Program** with timed sessions, and **Speakers** with bios linked to specific sessions.

---

### The Program

Open **Manage › Program › Sessions** and choose **Add session**. Add sessions one by one:

- **Title** — the talk or activity
- **Starts at / ends at** — exact times in the event's timezone
- **Description** — optional details
- **Speaker** — optional, linked from your speakers

Sessions are automatically grouped by day and shown in the **Program** section of the event page, in chronological order. The section's title opens the full list.

---

### Speakers

Open **Manage › Program › Speakers**. Add speakers (one row per person) with:

- **Name and photo**
- **Bio**
- **Optional links** — website, social handles
- **Linked sessions** — pick which sessions this person is speaking at

Speakers appear in the **Speakers** section of the event page, with chips linking to the sessions they're presenting.

---

### Organizers, partners and sponsors

On the web, open **Manage › Credits** and select **Add Credits**. Each entry is an organization with:

- **Name** and **Photo** — the logo
- **Role** — **Organizer**, **Partner** or **Sponsor**
- **Tier** — sponsors only; tier names show on the page only when more than one tier is used
- **Link** — the logo opens it

They appear at the bottom of the event page, in three sections — **Organizers**, **Partners** and **Sponsors** — each once it has someone in it.

---

### Who can edit

The event organizer and admins can add, edit, and remove sessions, speakers and credits. Moderators cannot.

---

### When NOT to use the Program

For a single-talk meetup or a casual gathering, the event description and timing fields are enough — the Program is overkill. Reach for it once you have **two or more sessions** worth listing separately.
