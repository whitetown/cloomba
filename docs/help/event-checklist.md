## Organiser checklist before the event

Use this checklist to make sure everything is in order before your event goes live — and before guests arrive on the day.

## Before publishing

- [ ] Title is clear and specific
- [ ] Cover image uploaded (square, 1:1 ratio)
- [ ] Date, time, and timezone are correct
- [ ] Location is set — or "Online" with a meeting link in the description
- [ ] Description covers what, who it's for, and any practical details
- [ ] Visibility is set correctly (public / unlisted / private)
- [ ] Capacity is set if you have a limit
- [ ] Ticket type configured if the event is paid
- [ ] RSVP approval turned on if you want to vet guests

## 1–2 weeks before

- [ ] Share the event link in relevant communities and channels
- [ ] Post to your Cloomba calendar if you have one
- [ ] Announce to your mailing list or social following

## Day before

- [ ] Send a reminder post or message to your audience
- [ ] Confirm the venue or online meeting link is working
- [ ] Review your guest list — check for any pending approvals

## Day of the event

- [ ] Open the guest list on your phone for check-in
- [ ] Have the check-in screen ready ([How to check in guests](/help/check-in))
- [ ] Post an event update if there are last-minute changes

## After the event

- [ ] Thank attendees with an event update or message
- [ ] Review what worked and adjust for next time
