## Add a Cloomba event to your calendar

When you RSVP to a Cloomba event, you'll see an **Add to calendar** option on the event page. Use it to put the event into your personal calendar so you get reminders.

### Google Calendar

Click **Add to Google Calendar**. A new tab opens with the event pre-filled — title, date, time, location, and a link back to the event page. Press **Save** to add it to your account.

### Apple Calendar (iPhone, Mac)

Click **Download .ics** (or use the **Add to Apple Calendar** option on iOS). The file opens in Apple Calendar — confirm the calendar you want to add it to and tap **Add**.

### Outlook and other apps

The **.ics** file works with Outlook, Thunderbird, Proton Calendar, and any other standards-compliant calendar app. Download the file and open it with your preferred app.

### Time zones

Cloomba stores each event with its own time zone. Your calendar will show the event in **your** local time, the same way Cloomba does on the event page — so an event at 19:00 Bratislava time shows up at 18:00 in Paris and 12:00 in New York.

### If the event changes

If the organiser updates the date, time, or location after you've added the event to your calendar, you'll need to re-add it. Calendar apps don't follow Cloomba's live updates; the **.ics** download is a one-time snapshot.

To stay in sync with changes, keep email and push notifications on — Cloomba notifies you when an organiser sends an update.
