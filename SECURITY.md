# Security Policy

We take the security and privacy of Cloomba users seriously. Cloomba is built EU-hosted and
GDPR-by-design, and we appreciate the work of security researchers who help keep it that way.

## Supported surfaces

| Surface            | Supported            |
| ------------------ | -------------------- |
| cloomba.com (web)  | ✅ latest             |
| iOS app            | ✅ latest App Store   |
| Android app        | ✅ latest Google Play |

We generally only fix security issues in the latest released version of each surface.

## Reporting a vulnerability

**Please do not open a public issue or discussion for security or privacy problems.**

Report privately, in either of these ways:

1. **GitHub private vulnerability reporting (preferred)** —
   [Report a vulnerability](https://github.com/whitetown/cloomba/security/advisories/new).
   This stays private between you and the maintainers.
2. **Email** — [support@cloomba.com](mailto:support@cloomba.com).

### What to include

- What the issue is and the surface it affects (web / iOS / Android).
- Steps to reproduce, or a proof of concept.
- The impact you think it has (e.g. data exposure, account takeover).
- Any logs, screenshots, or requests that help — please redact other people's personal data.

### What to expect

- We aim to acknowledge your report within **3 business days**.
- We'll keep you updated as we investigate and fix.
- We're happy to credit you once the issue is resolved, if you'd like.

## Safe harbour

We will not pursue or support legal action against researchers who:

- Report in good faith through the channels above.
- Avoid privacy violations, data destruction, and service disruption.
- Don't access or modify other users' data beyond the minimum needed to demonstrate the issue.
- Give us reasonable time to fix the issue before any public disclosure.

Thank you for helping protect the Cloomba community. 🔒
