# Contributing

Thanks for helping make Cloomba better! 🌱

Cloomba's source code is not public, so **there are no code pull requests here**. Your
contribution is your feedback — and good feedback is genuinely valuable to us. This guide helps you
make it count.

## Before you file

1. **Search first.** Check [existing issues](https://github.com/whitetown/cloomba/issues) and
   [Discussions](https://github.com/whitetown/cloomba/discussions). If your bug or idea already
   exists, add a 👍 or a comment instead of opening a duplicate.
2. **Pick the right place:**
   - Something broken → [Bug report](https://github.com/whitetown/cloomba/issues/new?template=bug.yml)
   - An idea or improvement → [Feature request](https://github.com/whitetown/cloomba/issues/new?template=feature.yml)
   - A question or open-ended idea → [Discussions](https://github.com/whitetown/cloomba/discussions)
   - A security or privacy problem → [report privately](https://github.com/whitetown/cloomba/security/advisories/new), never as a public issue

## Writing a good report

- **One issue per report.** Don't bundle several bugs together.
- **Be specific.** "Checkout button does nothing on iOS 17" beats "tickets broken".
- **Include steps to reproduce** — we can't fix what we can't see happen.
- **Tell us where:** web, iOS, or Android, plus the version and device.
- **Add screenshots or a recording** when it helps — but please don't include other people's
  personal data, or any payment details.

## What happens next

New issues start with a **`triage`** label. The team reviews them and applies labels as we go:

| Label                       | Meaning                                       |
| --------------------------- | --------------------------------------------- |
| `triage`                    | Awaiting first review                         |
| `needs-info`                | We need more detail from you to proceed       |
| `confirmed`                 | We've reproduced or accepted it               |
| `duplicate` / `invalid`     | Already tracked, or not actionable            |
| `wontfix`                   | We've decided not to pursue it                |

We're a small team, so responses may take a little time — but every report is read. Please keep
discussion friendly and on-topic; see our [Code of Conduct](./CODE_OF_CONDUCT.md).
